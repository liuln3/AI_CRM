## 用户原始想法

我想做一个轻量级的 AI+CRM 客户管理产品，帮助：

1. **一线销售**：认领线索、管理线索、分析线索；
2. **销售主管**：了解线索的获取和转化情况；
3. **销售团队**：获得定制化的推送

它应该是一个 Web 应用。

**一线销售侧**：
- 在系统的线索池里认领线索、查看自己负责的客户列表
- 管理客户名称、联系方式、跟进状态、最后联系时间等基础信息
- 进入客户详情页查看完整的沟通记录和跟进历史
- 不需要手动填写复杂表单：通过与 Agent 对话，直接粘贴一段聊天记录、客户备注、沟通内容，或上传会议纪要文档，提交客户跟进信息
- Agent 自动提取客户姓名、联系方式、需求、意向度、跟进状态等关键信息，并保存到客户管理系统（通过调用 LLM 分析）

**管理者侧**：
- 打开数据看板，查看客户总数、不同跟进状态的分布、本周新增客户、本月成交客户等关键指标
- 用图表展示客户状态或成交趋势

**全局 Agent**：
- 系统任意页面悬浮一个 Agent
- 打开后 Agent 能感知到当前所在页面，提供相关问题推荐
- 点击推荐问题直接发给 Agent 完成任务
- 例：在客户详情页，推荐"一键生成当前客户的分析报告"，点击后以当前客户信息作为上下文发送给 Agent，生成包括客户状态变化、重点客户提醒、潜在成交机会和后续跟进建议的分析报告

**推送**：
- 支持配置每天自动推送昨日客户动态摘要
- 例如：新增客户、状态变化、待跟进客户和重点提醒
- 帮助销售和管理者及时掌握客户进展

**基础能力**：
- 常规 CRM 的登录和权限管理系统都包含
- 当前只需要开发一个最小可行性产品，用于内部团队评审和套路
- 可生成模拟数据供体验，但同时要支持真实的操作、反馈和加工
